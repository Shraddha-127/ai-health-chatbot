# AI Health Chatbot

An AI-powered health chatbot that provides simple and general health-related information using **Ollama and Llama 3**. The application is built using Node.js and Express, with MongoDB used to store chat messages.

## Project Overview

The AI Health Chatbot is designed to provide users with general health information through a conversational interface. It uses the locally running Llama 3 language model through Ollama to generate responses to user queries.

The chatbot maintains conversation history and stores user and assistant messages in MongoDB.

## Features

- AI-powered health-related conversational assistant
- Uses Llama 3 through Ollama
- Provides simple and general health information
- Maintains conversation history
- Stores user and chatbot messages in MongoDB
- REST API for chatbot communication
- Node.js and Express-based backend
- HTML, CSS and JavaScript-based frontend
- CORS support for client-server communication
- Local execution without requiring an external AI API

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **AI Model:** Llama 3
- **AI Runtime:** Ollama
- **ODM:** Mongoose
- **API:** REST API
